# Постоянная политика ветвей и внедрение репозитория

Все репозитории Meitou -Modding-Ecosystem используют [центральную постоянную политику](https://github.com/TheIvoryDisaster/GutenStructure/blob/main/docs/branch-policy.md) :

| Ветвь | Требование |
| --- | --- |
| Обычные филиалы | незащищенный |
| бета | PR + прохождение CI ; супер-сопровождающие могут обходить проверку, включая самослияние |
| основной/выпуск | PR + прохождение CI + одно независимое одобрение супер-сопровождающего; нет обхода отзывов |

GitHub Actions не имеет обхода проверки. Исключение команды бета касается только обзоров: обязательная безопасность PR / CI не имеет обхода. CODEOWNERS не требует дополнительных утверждений.

Шаблоны GitHub копируют исходный код, а не наборы правил ветвей, разрешения группы, среды или секреты.  Средство настройки защиты ветки выпуска GutenStructure обнаруживает новые общедоступные репозитории организации ежечасно на 17-й минуте, назначает доступ на запись групповому репозиторию, если он отсутствует, и применяет политику. Чтобы немедленно настроить новый репозиторий, попросите авторизованного сопровождающего GutenStructure просмотреть его, а затем применить этот рабочий процесс в основной целевой организации. Сделайте это, прежде чем полагаться на защищенные слияния или публикацию. Оставьте Release readiness в вызывающем CI и проверяйте фактические проходы; ожидаемые проверки без соответствующего рабочего процесса будут ждать вечно.

Когда все будет готово, создайте основной/релиз из проверенного стабильного исходного кода; политика нацелена на них еще до того, как они существуют. Сохраняйте неизменяемые проверенные контакты центрального рабочего процесса этого шаблона, одновременно обновляя как ворота выпуска, так и издателя пакета с помощью PR. Частные репозитории требуют отдельной проверки плана/защиты; доступ к Azure не предоставляется при обнаружении. Секреты внешней платформы остаются в средах, принадлежащих автору, и никогда не копируются из этого шаблона.
