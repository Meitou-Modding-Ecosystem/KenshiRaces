# Постоянная политика филиала и хранилище на борту

Все хранилища Meitou-Modding-Ecosystem используют [Центральная постоянная политика](https://github.com/TheIvoryDisaster/GutenStructure/blob/main/docs/branch-policy.md):

| Бранч | Требования |
| --- | --- |
| Обычные отрасли | Незащищенный |
| Бета | PR + проходящий CI; супер-устройщики могут проходить обзор, в том числе самосоединения |
| Главная / Освобождение | ПР + проходящий ЦИ + одно независимое одобрение супер-устройств; нет пересмотра |

GitHub Actions не имеет пересмотра. Исключение команды Beta распространяется только на отзывы: обязательные PR/CI Безопасность не имеет байпаса. CODEOWNERS Не добавляет дополнительного требования к одобрению.

GitHub копирует источник, а не филиалы, разрешения на команду, среды или секреты. Защита от конфигурации GutenStructure открывает новые хранилища органа в час, а в случае отсутствия она предоставляет доступ к хранилищам. Для того чтобы установить новый реп, попросите уполномоченного подрядчика для предварительного просмотра, а затем применить этот рабочий поток на главную организацию. Сделайте это, прежде чем полагаться на защищенные слияния или публикации. Установить готовность к выходу в ЦИ и проверить реальные прохождения; ожидаемые проверки без соответствующего рабочего потока будут вечно.

Создать main/release Из пересмотренного стабильного источника, когда он готов; политика нацелена на них даже до их существования. Сохраняйте непрерывную проверку центрального рабочего потока этого шаблона, обновляя его как портал, так и издатель пакетов через PR. Отдых требует отдельного plan/protection Валидация; доступ к Azure не предоставляется через открытие. Внешние секреты платформы остаются в авторитетных средах и никогда не копируются из этого шаблона.
