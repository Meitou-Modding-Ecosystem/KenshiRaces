# 영구 지점 정책 및 저장소 온보딩

모든 Meitou -Modding-Ecosystem 저장소는 [중앙 영구 정책](https://github.com/TheIvoryDisaster/GutenStructure/blob/main/docs/branch-policy.md) :

| 나뭇가지 | 요구 사항 |
| --- | --- |
| 일반 지점 | 보호되지 않음 |
| 베타 | PR + CI 통과 ; 슈퍼 관리자는 자체 병합을 포함한 검토를 우회할 수 있습니다. |
| 메인/릴리스 | PR + CI 통과 + 하나의 독립적인 슈퍼 관리자 승인; 리뷰 우회 없음 |

GitHub Actions에는 검토 우회 기능이 없습니다. 베타의 팀 예외는 검토에만 적용됩니다. 필수 PR / CI 안전에는 우회가 없습니다. CODEOWNERS 는 추가 승인 요구 사항을 추가하지 않습니다.

GitHub 템플릿은 분기 규칙 세트, 팀 권한, 환경 또는 비밀이 아닌 소스를 복사합니다. GutenStructure 의 릴리스 분기 보호 구성은 매시간 17분에 새로운 공개 조직 저장소를 검색하고, 누락된 경우 팀 저장소 쓰기 액세스 권한을 할당하고 정책을 적용합니다. 새 리포지토리를 즉시 구성하려면 승인된 GutenStructure 관리자에게 미리 본 후 기본 대상 조직에 해당 워크플로를 적용하도록 요청하세요. 보호된 병합이나 게시를 사용하기 전에 이 작업을 수행하십시오. 호출자 CI 에 Release readiness 를 유지하고 실제 통과 실행을 확인합니다. 일치하는 워크플로가 없는 예상 검사는 영원히 기다리게 됩니다.

준비가 되면 검토된 안정적인 소스에서 메인/릴리스를 생성합니다. 정책은 존재하기 전에도 이를 목표로 삼습니다. 이 템플릿의 불변 검토 중앙 워크플로 핀을 유지하여 PR을 통해 릴리스 게이트와 패키지 게시자를 함께 업데이트합니다. 프라이빗 저장소에는 별도의 계획/보호 검증이 필요합니다. 검색을 통해 Azure 액세스 권한이 부여되지 않습니다. 외부 플랫폼 비밀은 작성자 소유 환경에 유지되며 이 템플릿에서 복사되지 않습니다.
