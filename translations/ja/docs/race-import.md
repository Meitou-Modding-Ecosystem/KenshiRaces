# レースのインポート: ボディをゲームのスケルトンにフィットさせる

`tools/RaceImport` は、リグ付き `.glb` ボディ ( Meshy 、 Hi3D : 「3ds Max Biped」リグ、ジョイント `Bip001 ...` ) を、ゲームが独自のヒューマン アニメーションでアニメーション化するボディ ( `male_skeleton.skeleton` または `female_skeleton.skeleton` 、その DDS テクスチャ、およびパーツ マップにリンクされたスキン付きの Ogre メッシュ) に変換します。ゲームのインストールからリグのスケルトン、人体、パーツ マップを読み取るため、 CI ではなく、 Kenshi を備えたマシン上で実行されます。その出力はコミットされます。

<a id="run-it"></a>
## 実行してください

```powershell
dotnet run --project tools/RaceImport -c Release -- <model.glb> <Kenshi folder> KenshiRaces/items/races kenshiraces_<character> [male|female] [slim]
```

- `<Kenshi folder>` : ゲームフォルダー (その中に `data/` )、例: `"C:\Program Files (x86)\Steam\steamapps\common\Kenshi"` 。
- ステムはファイルに名前を付け、MOD 全体で一意である必要があります (ゲームは裸の名前でファイルを検索します): `<modfolder lower case>_<race>` 。
- `male` / `female` : リグ、デフォルトのオス。女性の身体を `female_skeleton` に装着し、 `human_female.mesh` および `FemaleMask_Default.png` と比較して測定します (ゲーム内の女性のアニメーションと音声、編集者のバスト スライダー)。男性のものは `male_skeleton` 、 `human_male.mesh` 、 `MaleMask_Default.png` です。
- `slim` : 0 ～ 1、デフォルトは 1 ([痩身](#slimming) );衣服よりもかさばるレースの場合は、それを下げます。
- `<stem>.mesh` 、 `<stem>_d.dds` 、 `<stem>_n.dds` (モデルに法線マップがある場合のみ) および `<stem>_parts.png` を書き込みます。ログ行には、頂点の数、スケール、境界、および非表示部分に含まれる頂点の数が表示されます。
- `.glb` をリポジトリの外に保持します (数十の MB )。 4 つの出力をコミットします。 `.gitignore` は `*/items/races/*.mesh` と `*.dds` を通過させます。
- 依存する MOD は、独自の出力フォルダー ( `<Mod>/items/races` ) とステムを備えた KenshiRaces クローンから実行します。

<a id="what-the-model-needs"></a>
## モデルに必要なもの

- スキンに Biped ジョイント `Bip001 Pelvis` 、 `Spine` 、 `Spine1` 、 `Spine2` 、 `Neck` 、 `Head` 、両方の `Clavicle` 、 `UpperArm` 、 `Forearm` 、 `Hand` 、 `Thigh` 、 `Calf` が含まれる 1 つのスキン メッシュ頭上の `Foot` 、 `Toe0` 、および `mixamorig:HeadTop_End` 。追加のジョイント(指、尾、ヘルパー)は、最も近い Biped 祖先に従います。 **検証済み** Leoma 、 Crevan 、Crabman and the Crab Queen ( Meshy エクスポート)。
- ベースカラーのテクスチャ。金属的な粗さと通常のテクスチャが存在する場合は使用されます。
- 任意のレスト ポーズ: T ポーズと A ポーズの両方がフィットします (ゲームのバインド ポーズは腕を下げています)。

<a id="how-the-fit-works"></a>
## フィットの仕組み

1. すべての頂点は、ファイルが示すレスト ポーズにスキンされます(バインド時間のジョイントレストの逆変換)。
2. スケール: モデルの頭部ジョイントの最も低い頂点の上のゲームの頭ボーンの高さ。
3. ゲームと同じように、脊椎、腕、脚の各ボーンが関節から子を指すように回転し、ゲームの長さ (0.6 ～ 1.6 倍) まで引き伸ばされます。
4. 骨盤、背骨、首、鎖骨は 1 つの硬い部分 (ゲームの首、肩、股関節の最小二乗) としてフィットするため、胸の形が維持されます。骨ごとのフィットは、脊椎と鎖骨の重みがブレンドされる場所で剪断します。骨盤と脊椎のジョイントはそのフィットから除外されています。ゲームの骨盤は腰と同じ高さで、Biped エクスポートはその上にあり、胸部が 1 ユニットほど下がっています。
5. 頭は胴体がゲームの頭関節に運ぶ場所の途中で着地するため、そのメッシュは骨の下に位置します。ゲームの首は肩から約 1 ユニット上がりますが、これらのモデルはかろうじて伸びます。関節に頭を置くと、首が長さの約 3 倍に伸びました (**観察** オスの Leoma 、クラブマンとクラブ クイーン: 首のフィット感は 2.4 ユニット、モデル自身の 0.8 ユニット、ゲームの 1.4 ユニット)。
6. 足は直立を保ち、足の裏が地面に着地するように押しつぶされます（足とカニの足はゲームの足よりも高いです）。
7. 各頂点は、そのジョイントのフィットの重み付き合計です。その重みはそのジョイントに続く獲物の骨に割り当てられ、最も重い 4 つが保持されます。

**検証済み**: C# ツールのメッシュは、Crabman の元の Python プロトタイプ (1e-5 単位内の位置、同一のボーン ウェイト) と一致します。

<a id="slimming"></a>
## 痩身

ゲームの衣服はリグの人体を中心にモデル化されているため、体が透けて見えるよりも大きくなります。このツールは、各胴体と四肢の骨 (骨盤、脊椎、鎖骨、上腕、下腕、脚) の周囲で、骨の 6 分の 1 あたり、および骨の周りの 12 回転あたりの人体の最も遠い範囲を測定します。その範囲に 0.15 単位 (布の 1.5 cm) を加えた範囲を超えてフィットした頂点は、その余剰部分の 5 分の 1 を保持し、その修正はボーンの重みによってブレンドされます。補正は、制限の 1.5 倍から 2.5 倍の間でフェードアウトし (それを超えると、爪などの付属物は放置されます)、骨のスライスの外側の頂点 (骨盤の下に垂れ下がった尾) はゼロになり、サーフェス上で平滑化されるため (12 ラウンドの隣接平均化、UV シームの溶接)、隣接する頂点は同じように動きます。 **観察結果** (男性 Leoma ): 頂点の 39% が平均 1.3 cm、最大 9.5 cm 移動します。

<a id="bust"></a>
## バスト

女性の身体のバストは、人間の女性のバストよりも高くなります (**観察結果**: Leoma と Crevan の女性は、衣服の胸部とパーツ マップのバストの下に 2.0 単位と 1.75 単位低く座っていました)。バストは、4 分の 1 単位のスライスの中央で、 `Spine1` と肩の間で、中央線から 0.3 ～ 1.8 単位横にあり、その最前面の頂点が最も前方にあります。各頂点は、胴骨の重量とバストからの高さの exp(-(dy / 1.5)²) を掛け、背骨の深さ (0) からバストの深さ (1) までのスムーズステップを掛けた差によって上昇するため、背中、腕、脚は維持されます。それからスリミングランニング。

<a id="human-only-bones"></a>
## 人間だけの骨

女性のスケルトンには `L Boob` と `R Boob` (エディターの胸のサイズ、高さ、間隔のスケールと移動、engine docs/animation.md) がありますが、これは Biped リグにはありません。スリム化後、最も重いボーンが `Spine1` または `Spine2` である各頂点は、1 単位以内で 1 - 距離でスケールされた、最も近い人間の頂点の人間専用の重みを受け取ります。スペースを作るためにそれ自体の重みが小さくなります。 **観察** ( `human_female.mesh` ): バストの頂点は 2 つのボーン (前胸の頂点 994 個のうち 892 個) によって保持されます。ボーン ( `L Boob` 28、 `R Boob` 29) と女性のリグの他のハンドルは男性のハンドル ( `R Clavicle` 23 対 25、男性のハンドルは `Bip01 Jaw` ) とは異なるため、メッシュは常に独自のリグのハンドルに対して書き込まれます。

<a id="part-map"></a>
## パーツマップ

レースの `part map male` / `female`  PNG は、各頂点が属する体の部位をマークします。着用アイテムの `hide parts` は、それらのパーツの描画を停止します (engine docs/characters.md "Hidden body Parts")。このツールは、フィットした各頂点に、同じボーンに含まれる最も近い人体の頂点の一部を与え、その頂点の UV でリグのパーツ マップから読み取って、フィットした頂点自身の UV (1024 × 1024、他のテクセルは透明) に書き込みます。人間の各パーツは、まず 0.8 単位ずつ拡大されます (パーツのない頂点は、その距離内で最も近いマークされた頂点の頂点になります)。これは、体が大きくなるほど、より広い帯域にわたってクリップされるためです。

**観察** ( `MaleMask_Default.png` 、256²、ゲームがサンプリングするため `human_male.mesh` uv でサンプリング): 15,504 個の頂点のうち 642 個に一部があります: 胸の上部と肩の上部が赤、上腕の周りに白い帯、腹部の前面が緑です。  基本データ (rebirth.mod) の `hide parts` : ドリフターとパッド付きレザー ジャケット 1、ノースリーブ ロングコートとダストコート 2、ロングコートとダストコート 3、忍者着とラグ 4、ローブ 5、プレート ジャケット、スキン スーツ、クラブ アーマー 7。ホーリー サーヴァント ラグ、モンク パンツ、フード 0。0 の付いたアイテムは何も非表示にしません。痩身はそれらをカバーします。 **観察** ( `human_female.mesh` uvs での `FemaleMask_Default.png` ): バストは赤 (頂点 1,102)、上腕バンドは白 (頂点 560)、腹部は緑 (250)。

<a id="textures"></a>
## テクスチャ

- `_d` : 基本色、アルファ = 光沢 = (255 - 粗さ) / 2 (マップなしの粗さ 200)。 2048²、ミップ付きBC3。
- `_n` : ゲームのキャラクター レイアウト、X はアルファ、Y は緑、Y は glTF の +Y から反転しました。赤と青0。
