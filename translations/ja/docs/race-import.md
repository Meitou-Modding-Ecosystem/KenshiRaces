# レース輸入:ゲームの骨に体を調整する

`tools/RaceImport` ひきこもり ひくこもり `.glb` 体(Meshy, Hi3D「3ds Max Biped」のリグ、関節 `Bip001 ...`) 体の中では、ゲームは自分の人間のアニメーションでアニメ化されます: 皮のオグレのメッシュが結びついている `male_skeleton.skeleton` あるいは `female_skeleton.skeleton`彼女の DDS テキストと地図の一部 ゲームインストールからリッジの骨と人間の体と部分の地図を読み、それは機械で走る。 Kenshi決して、その生産が決まらない。

<a id="run-it"></a>
## 走る

```powershell
dotnet run --project tools/RaceImport -c Release -- <model.glb> <Kenshi folder> KenshiRaces/items/races kenshiraces_<character> [male|female] [slim]
```

- `<Kenshi folder>`ゲームフォルダー(`data/` 内側(など) `"C:\Program Files (x86)\Steam\steamapps\common\Kenshi"`.
- パッケージはファイルを名付け、モードでユニークでなければなりません(ゲームはバラ名でファイルを見つける) `<modfolder lower case>_<race>`.
- `male` / `female`リッジ、デフォルト・マン 女性の体は、 `female_skeleton` 測定された対 `human_female.mesh` そして、
`FemaleMask_Default.png` (女性のアニメーションとゲームの声、編集者のブストスライダー) `male_skeleton`, `human_male.mesh` そして、 `MaleMask_Default.png`.
- `slim`0 から 1 まで、デフォルト 1 ([弱体化](#slimming)レースは、その服よりもブルキアになることを意味するために低下します。
- 書き込み `<stem>.mesh`, `<stem>_d.dds`, `<stem>_n.dds` (モデルが通常の地図を持っている場合のみ) `<stem>_parts.png`ロゴラインは、
垂直数、スケール、範囲、そしてどれだけの垂直が隠れる部分に落ちるか。
- 持って行き `.glb` 外のレポ(MBのトン)で、4つの出力を取る。 `.gitignore` ラッキー `*/items/races/*.mesh` そして、 `*.dds` 通り過ぎる。
- クロアチアのクローンから、独自の出力フォルダーでそれを実行する。`<Mod>/items/races`」と投票。

<a id="how-the-fit-works"></a>
## どのように機能するか

1. すべての垂直は、ほかのファイルをポーズ(逆の結合時間の合成休憩変換)に塗り込まれています。
2. スケール:ゲームの頭骨の高さは、モデルの頭関節の上に、その最低の垂直。
3. 背中、腕、足の骨は、ゲームの長さまで、その関節からその子供に指摘されます。
(6〜6回)
4. ペルヴィス、スパイス、ネックレス、クラウイクは一つの硬い部分(ゲームの首、肩および足の関節に最小の平方形)として装備されています。
形を保ち、脊椎とクラヴィクルの重さが混合する場所に、それぞれに合う。 腰と脊椎の関節は、その上に、胸を落とす一つのユニットと平らです。
5. 頭部は、トルソがゲームの頭部に連れて行く場所から半分に落ちるので、そのメッシュは骨の下に置かれます。 ゲームの首が上がる。

<a id="slimming"></a>
## 弱体化

ゲームの衣類はリッジの人体の周りにモデル化され、それが示すほどのボリュームです。 各トルソおよび脊椎骨(<unk>、脊椎、クラウイク、上部および下部の腕および足)の周りでは、道具は、骨の6分の1とその周りの回転の12分の1で人間の体の最長の範囲を測定し、その範囲を超える固定の垂直と0.15単位(1.5cmの衣類)は、その過剰の5分の1を維持し、その修正は骨の重さによって混ぜられています。 修正は、限界の1.5〜2.5倍の間で行われます(左側のクラウドのような補足)は、骨の下に横たわる背中がゼロであり、表面上に柔らかくなります(近所の平均的な12回目、近所の垂直が溶けます)。 **観察** (男) Leoma):垂直の39%が移動し、平均で1.3cm、最大で9.5cm。
