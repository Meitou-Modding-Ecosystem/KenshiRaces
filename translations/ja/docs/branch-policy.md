# 継続的な分支政策とリポジトリの上昇

すべての Meitou-Modding-Ecosystem リポジトリは、 [中央常設政策](https://github.com/TheIvoryDisaster/GutenStructure/blob/main/docs/branch-policy.md):

| ブランチ | 要件 |
| --- | --- |
| 普通の分野 | 無保護 |
| ベータ | PR + 通過 CI; スーパーメンテナンスは、自己調節を含む、レビューを過渡することがあります |
| メイン / リリース | PR + 通過 CI 統合された 1 つの独立したスーパーメンタナーの承認; レビュー バイパスなし |

GitHub アクションにはレビューバイパスはありません。 ベータチームの例外は、レビューのみに適用されます:義務 PR/CI 安全にはバイパスがない。 CODEOWNERS 追加の承認要件を追加することはありません。

GitHub はコピーソース、分野のルールセット、チームの許可、環境、または秘密を提供します。 GutenStructure の Configure リリース セキュリティ は、17 分で新しいオーガニック リリースを発見し、欠けている場合はチーム リリースのアクセスを割り当てます。 新しいリポを直ちに設定するには、事前表示の権限を有するGutenStructureのメンバーに要求し、その作業流を主なターゲット組織に適用します。 保護された合金や出版物に頼る前に、これを行う。 リリース準備は、Caller CI で実行されますが、予想されるチェックは、適合する作業の流れが永遠に待っています。

創造 main/release 見直しの安定した情報源から、準備が整ったとき、政策はそれらが存在する前に、それらをターゲットにします。 このテンプレートの変動性の中心的なワークフローを維持し、PRを通じてリリースゲートとパッケージエディターを更新します。 プライベートリゾートは別々に必要です。 plan/protection 認証: 発見によって Azure アクセスが与えられません。 外部のプラットフォームの秘密は、著者が所有する環境に残り、このテンプレートからコピーされません。
